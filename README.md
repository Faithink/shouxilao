# 收息佬 · 股息攒得好，退休晚不了

**[▶ 在线演示（不用安装，打开就能玩）](https://faithink.github.io/shouxilao/)** · [下载桌面版 / 手机版](#下载) · GPL-3.0 开源

A 股 / 港股 / B 股红利股的本地研究工具：红利股票池 → 个股详情（股息率、价格位置、公司体检）→ 持仓与红利税测算。数据都在你自己的电脑上，不上传任何持仓。

> 在线演示是只读的静态页：股票池是某一天的数据快照，持仓是虚构的示例；你在演示里的改动只保存在自己的浏览器里。刷新数据、添加/移出股票需要本地后端，请用桌面版。

> **免责声明**：本项目仅供学习研究，不构成任何投资建议。数据来自新浪财经、东方财富等公开接口，可能有延迟或错误，请以公司公告和券商为准。


第一次打开用的是仓库里自带的股票池快照；在「设置」页点「刷新数据」重新采集（约 5~8 分钟）。

## 使用

双击 `start.command`(或终端运行 `.venv/bin/python app.py`),浏览器打开 http://127.0.0.1:8890。
在「设置」页点「刷新数据」重新采集全部股票(约 3 分钟);建议每周刷新一次,分红公告季更勤些。

点页头的 logo 或标题回到首页(同时清除筛选)。每个页面都有独立地址,浏览器的前进/后退可用,也可以收藏:`/#/`(股票池)、`/#/hold`(持仓)、`/#/settings`(设置)、`/#/stock/600941`(个股详情)。

股票池默认显示「★ 重点关注」:你关注的股票(点列表左侧的 ☆ 加入,持仓自动算入,排在前面)加上系统精选(带「精选」标签:价格偏低或低位、体检无质量红灯、区间可信)。「全部」是完整列表。

## 手机与局域网访问

服务对局域网开放:电脑上双击 `start.command`,终端里会打印「局域网: http://192.168.x.x:8890」,手机连同一个 WiFi 后用浏览器打开即可。

- **只接受内网访问**:192.168.x.x、10.x.x.x、172.16-31.x.x 和本机,公网 IP 一律拒绝。
- **访问密码(可选)**:终端运行 `.venv/bin/python passcode.py 你的密码` 设置,`--off` 关闭。密码以加盐哈希存在 `access.json`,删掉这个文件也等于关闭。没设密码时,同一 WiFi 下的人都能看到你的持仓,公共 WiFi 下务必设密码或关闭服务。
- **存成 webapp**:iPhone 用 Safari →「分享」→「添加到主屏幕」,从主屏幕图标进入就是全屏 App(带底部标签栏)。安卓 Chrome →「添加到主屏幕」;局域网是 http 地址,安卓只能做成快捷方式。
- 手机端是单独排版的:底部三个标签、股票池按卡片显示(行业和排序用下拉框)、触控区放大、输入框不会触发 iPhone 自动缩放。主屏幕图标是深色底版本;如果之前已经添加过,请删掉再重新添加,iPhone 才会换新图标。
- 电脑要开着、程序要在运行。首次开放局域网时 macOS 可能弹出「是否允许 Python 接受传入网络连接」,点「允许」。

## 设置页

外观(跟随系统/浅色/深色)、刷新数据、买入要求(国债收益率 + 行业溢价)、个股单独设定(可搜索,拼音可用)都在「设置」里。关注列表、溢价、单独设定保存在 holdings.json,外观保存在浏览器里。

## 三个页面

- **红利股票池**:每只股票给出价格位置(低位/偏低/适中/偏高/高位)、价格位置条、买入价、股息率、分红节奏。可按状态和行业筛选,支持名称/代码/拼音搜索,在「设置」里调国债收益率和行业溢价。
- **个股详情**(点股票进入):价格区间条、股价 vs 含分红再投 10 年曲线、股息率 5 年走势(含买入/止盈线)、年度分红柱图、分红节奏月份、年度明细(含分红率)、历次分红与已公告方案。
- **我的持仓**:按批次录入买入日期/价格/数量。给出成本股息率、浮盈、加仓/止盈节点、仓位上限提示、未来 12 个月分红月历,以及税前/税后分红与红利税预估、各批次免税倒计时。

## 区间与节点怎么算

股息率 = 最近一个已分完的完整财年的每股分红合计 ÷ 现价(分红按报告期归入所属财年,避免中期分红提前或推后时,一年内被重复计入)。买入价 = 每股分红 ÷ 要求股息率;自身近 5 年历史只做提示(当前股息率低于它自己的近 5 年中位数时标 ⚠),不参与决定。

**买入要求 = 10 年期国债收益率 + 行业风险溢价**(股债利差框架)。国债收益率默认 1.65%(2026 年 10 月中旬参考值,需手动更新),在「设置」页调整;行业溢价默认值是经验取值(电力 2.3、消费 2.0、交通 2.8、通信 3.0、银行 3.3、保险 3.0、油气 4.0、煤炭 4.5、建材 4.0、航运 5.0),也可逐行业调整,个股详情页可单独覆盖。国债变动时所有下限自动跟着变。「低位」用「要求 +1%」作分界。

**周期股**(煤炭、油气、航运、建材)的分红随景气波动,股息率改用「近 3 个完整财年平均分红」计算,避免在景气高点被虚高的股息率误导。

五档只表达**价格相对你的要求处于什么位置**,和仓位、操作无关(加仓/减仓参考只出现在「我的持仓」):

| 档位 | 含义 |
|---|---|
| 低位 | 价格 ≤ 分红 ÷ (要求 +1%),股息率比你的要求还高 1 个点以上 |
| 偏低 | 价格 ≤ 分红 ÷ 要求,股息率达到你的要求(这个价就是「买入价」) |
| 适中 | 买入价以上,到 30 分位股息率对应的价格(至少高于买入价 10%) |
| 偏高 | 适中之上,到 15 分位对应的价格 |
| 高位 | 价格 ≥ 分红 ÷ 15 分位股息率,股息率处在它自己近 5 年最低的一档 |

体检红灯、股价大跌不改写档位,单独用 ⚠ 提醒行显示;带红灯的排在后面,也不进系统精选。

持仓页节点(参考):加仓一档 = 买入价;加仓二档 = 低位线与成本价 -10% 取低;止盈一档 = 高位线;止盈二档 = 高位线 ×1.15。每档动 1/3 仓位。单票仓位上限和总资金在持仓页设置。

这是用历史股息率自我比较的经验规则,没有预测未来分红,也不考虑基本面变化(分红率下滑、盈利恶化时要自己判断)。

## 公司体检(五项红绿灯)

股息率之外,判断这家公司值不值得持有。每项独立评级,**不合并总分**;股票池里「体检」列是五个小圆点,详情页有完整体检卡(带图)。价格偏低或低位的股票遇到质量类红灯(分红能力/盈利质量/分红稳定/财务安全),列表里会另起一行 ⚠ 提醒(档位本身不变),并排到后面、不进系统精选。

| 项目 | 看什么 | 绿 | 黄 | 红 |
|---|---|---|---|---|
| ① 分红能力 | 分红率(分红÷每股收益)、近3年经营现金流÷分红 | 分红率 ≤80%,现金流 ≥1.5 倍 | 80~100%,1.0~1.5 倍 | 分红率 >100%(分的比赚的多),现金流 <1 倍 |
| ② 盈利质量 | 近5年平均 ROE、净利润明显下滑(降超10%)次数、经营现金流÷净利润 | ROE ≥10%(金融 ≥9%),无下滑 | ROE 6~10%、下滑1次或连降3年、现金含量 0.5~0.8 | ROE <6%、下滑 ≥2 次、最近一年降超30%、现金含量 <0.5 |
| ③ 分红稳定 | 连续分红年数、近5年每股分红下降(较上年降超10%)次数、是否含特别分红 | 无下降且连续 ≥5 年 | 下降1~2次、疑似特别分红、连续 3~4 年;**或曾被砍但已恢复**(分红回到被砍前水平、最近两年稳定、分红率正常) | 单次降超25%、连续两年下降、降3次、连续 <3 年(已恢复且稳定的除外)。上年分红率超过100%的特殊高分红年份回落,不算被砍 |
| ④ 财务安全 | 资产负债率 | ≤50%(电力/交通/公用事业 ≤60%) | ≤70%(≤75%) | 超过 |
| ⑤ 估值 | PE(金融、周期股用 PB)在自身近5年的分位 | ≤40% | 40~75% | >75% 或亏损 |

数据:新浪财务摘要(ROE、净利润、负债率、每股收益/净资产/经营现金流)。局限:经营现金流未扣资本开支,不等同自由现金流;缺有息负债与利息覆盖;银行/保险不看负债与现金流;近5年有送转的股票历史估值分位不可用;阈值是经验取值,仅作筛查。

## 配置分析与风险分类

溢价来自风险,所以配置上不是股息越高越好。工具把行业归成四类风险属性:**防御型**(电力、公用事业、通信、交通)、**金融型**(银行、保险)、**成长型**(消费、医药)、**周期型**(煤炭、油气、航运、建材、汽车)。

- 「我的持仓」顶部有「配置分析」:四色堆叠条看钱分在哪几类风险上;每类的占比、加权股息率、平均溢价;按行业的分布;组合平均溢价 vs 组合预计股息率(补偿够不够);集中度等提示。可以设置自己的配置目标,设了就显示偏离。
- 个股详情和持仓卡片的名字旁有类别标签。
- 「我的持仓」里还有「含息总收益」:价差(浮盈)+ 买入后已收分红(按各批次买入日之后、股权登记日之前已持有的除息记录估算)− 若今天卖出需补的税,按股票列出价差和分红各占多少。持仓卡片上也有这一行。
- 配置目标的偏离提示用的是再平衡规则:偏离 ≥5 个百分点,或相对目标 ≥25% 才提示;调整时先用新增资金和分红补低配的类别,不急着卖高配的;A 股持股一年以内卖出,分红要补税,别为调仓打断持股期限。
- 分类是按行业的粗略归类(代码里的 `STYLES`),同一行业里个股的风险也会不同;提示和目标不构成投资建议。

## 红利课堂(知识页)

「知识」标签顶部有目录,点击可平滑跳转到对应章节,往下滚动后右下角有「↑ 目录」按钮可以一键回到目录。内容是可视化、可拖动的入门课:红利怎么赚钱、股息率的两面(拖动股价和分红看变化)、股息率不等于收益率(总回报 = 分红 + 价差)、溢价来自风险(随你的设置变化的阶梯图)、四类资产各司其职与配置思路示意、红利 ETF(是什么、分红不是额外收益、与个股/REITs 的差别、选 ETF 看什么、费用怎么吃掉收益、怎么用收息佬看 ETF)、红利再投 vs 分红花掉(同样的钱差在哪:1,000 股的例子 + 可拖动的对比)、攒股息模拟器(多久能靠股息覆盖开销)、红利税、登记日与除息日、收息佬五步用法、常见误区。

## 红利税

个人持股 ≤1 个月 20%、1 个月~1 年 10%、>1 年免税。持股一年以内的,分红时暂不扣税,卖出时按持股期限补缴;持股超过一年免征。工具按批次、按「持有到分红日」的持股期限估算,以券商清算为准。

## 数据

- 分红:东方财富;日线和财务摘要:新浪财经。本机装了 akshare 就优先用它取数(`datasrc.py` 里的 `SOURCE`),失败时自动退回自带的标准库请求(腾讯作日线备用);打包给别人的 .app 不带 akshare,直接用自带请求。`SHOUXI_SOURCE=native` 可强制不用 akshare。
- 日线只在第一次完整下载,之后每次只补最近几天(缓存在 `data/cache/`),价格可能比实盘晚一个交易日。
- 股价收益按送转调整;含分红再投用自己算的总回报指数(现金分红在除息日收盘价再投)。
- 预计分红:已公告的按公告,其余按去年节奏与金额顺延,不含增长假设。

## 检查更新

设置页最下面有「检查更新」,程序每天也会自动查一次。它读公开仓库 `Faithink/shouxi-update` 里的 `latest.json`(只有版本号、更新说明、下载页,不上传任何数据)。发新版时:改项目里的 `VERSION`,打包,再更新那个仓库里的 `latest.json`(`version`、`notes`、`download` 网盘链接、`code` 提取码),用户就会在页面顶部看到提示。

## 打包成 Mac 应用(给别人用)

```bash
bash packaging/build.sh
```

产物在 `packaging/build/`:`收息佬.app`(约 29 MB)和 `收息佬.dmg`(约 10 MB)。结构:一个 124 KB 的 Swift 菜单栏小程序(菜单栏显示「息」,启动内置服务并打开浏览器)+ PyInstaller 打包的精简 Python 服务 + 出厂股票池和行情缓存(第一次打开就有数据可看)。

- **数据每台电脑独立**:持仓、自选、设置、行情都在 `~/Library/Application Support/收息佬/`,首次运行时从出厂数据复制,不会带上你自己的持仓。
- **没有苹果开发者签名**(只做了本地签名),别人第一次要右键→打开,说明在 dmg 里的「安装说明.txt」。
- 目前只构建 Apple 芯片(arm64)、macOS 11+。Intel Mac 需要另用 x86_64 的 Python 构建一份。
- 构建需要 `uv`、Xcode 命令行工具;`build.sh` 会自动建 `.build-venv`(便携 Python 3.12)。

仅供研究参考,不构成投资建议。
