# 架构与代码地图

## 1. 总览

```
浏览器 / WebView ──HTTP──▶ app.py（标准库 http.server，仅局域网）
                              │  读写 holdings.json / stocks.csv / data/*.json
                              └─▶ fetch_data.py（采集+指标计算）──▶ datasrc.py（数据源请求）
前端：web/index.html 单文件（无构建、无外部依赖），所有计算展示都在浏览器里做
```

- **后端只用 Python 标准库**（`segno` 仅用于二维码；`certifi` 可选）。不依赖 pandas / numpy。开发机装了 akshare 时 A 股优先走它，失败退回自带请求；打包版不带 akshare。
- **前端单文件**：HTML + CSS + JS 都在 `web/index.html`（约 1500+ 行），模板字符串渲染，无框架。
- **数据全部本地**：持仓、自选、设置、行情都在用户电脑上，每台机器独立。

## 2. 文件职责

| 路径 | 作用 |
|---|---|
| `app.py` | HTTP 服务、路由、访问密码、局域网限制、检查更新、添加/移除个股、静态文件 |
| `fetch_data.py` | `compute(code,name,industry,today)` 计算单只股票全部指标并写 `data/stocks/<code>.json`；`run(only=…)` 批量刷新并写 `data/pool.json`、`data/status.json`；`load_prices` 日线增量缓存 |
| `datasrc.py` | 数据源：`kind/ccy_of/fx_rate`、分红（A 股/ETF/港股/B 股）、日线（新浪/东方财富/腾讯）、财务摘要；akshare 后端与回退 |
| `paths.py` | 路径集中管理、`VERSION`、`ensure_home()`（首次种子复制 + 升级合并）、`read_text_any/load_json`（UTF-8 优先、GBK 兜底） |
| `passcode.py` | 命令行设置/关闭访问密码 |
| `stocks.csv` | 股票池：`code,name,industry`；行业写 `ETF` 表示 ETF |
| `holdings.json` | 用户私人数据：`settings`（国债收益率、行业溢价、个股覆盖、资金、仓位上限…）、`lots`（买入批次）、`sells`（卖出记录） |
| `data/pool.json` | 股票池汇总（每只一条）；`data/stocks/<code>.json` 个股详情；`data/cache/<code>.json` 不复权日线缓存；`data/status.json` 刷新进度 |
| `web/index.html` | 前端全部代码；`web/changelog.md` 版本说明（设置页「关于」里内嵌渲染）；其他静态资源（图标、manifest） |
| `VERSION` | 唯一版本号来源（`paths.VERSION`、打包脚本、安卓 gradle、页脚都读它） |
| `packaging/` | Mac 打包（`build.sh`、Swift 菜单栏启动器、图标、`INSTALL.txt`）、Windows 打包（`build_win.ps1`、`win_smoke.ps1`、`INSTALL_WIN.txt`）、`seed/`（出厂数据，打包时生成） |
| `android/` | 安卓轻量壳（WebView 打开电脑上的收息佬，首次输入电脑地址） |
| `android-standalone/` | 安卓独立版（Chaquopy 在手机里跑 Python 服务 + WebView）；`android_entry.py`、`scripts/prepare.sh`、模拟器测试脚本 |
| `.github/workflows/` | `build-windows.yml`、`build-android.yml`、`build-android-standalone.yml`（`v*` 标签触发） |
| `README.md` / `DESIGN.md` / `docs/` | 使用者说明 / 视觉规范 / 本交接文档 |
| `start.command` | 开发时双击启动 |
| `deep-research-report.md`、`红利类资产入门….pdf` | 早期的研究资料，非运行所需 |

## 3. 运行目录与数据目录

- **开发模式**（未打包）：数据在项目目录。
- **Mac 打包版**：`~/Library/Application Support/收息佬/`；**Windows**：`%APPDATA%\收息佬\`；**安卓**：应用私有目录。
- 首次运行从出厂种子（`seed/`）复制股票池和行情；**升级合并**：新版出厂池里新增的股票会补进用户的股票池（用 `seed_codes.json` 记录上次出厂列表，用户自己加/删的不动，持仓不动）。
- 打包的出厂数据**不含**持仓、访问密码、状态文件。

## 4. 环境变量（测试/打包常用）

| 变量 | 作用 |
|---|---|
| `SHOUXI_HOME` | 指定数据根目录（隔离测试用，如 `/tmp/sx_ui`） |
| `SHOUXI_PORT` | 指定端口（开发服务 8890；测试服务用 8897/8898） |
| `SHOUXI_SOURCE=native` | 强制不用 akshare，走自带请求（测试打包版行为） |
| `SHOUXI_BIND` | 监听地址（默认局域网；安卓独立版只绑本机） |
| `SHOUXI_RES` | 资源目录（打包后网页与种子所在位置） |
| `SHOUXI_ANDROID` | 安卓独立版标记 |
| `SHOUXI_UPDATE_URL` | 覆盖检查更新读取的 `latest.json` 地址（测试用） |

## 5. 接口（`app.py`）

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/pool` | 股票池汇总（附拼音 `py/pyfull` 供搜索） |
| GET | `/api/stock/<code>` | 个股详情（代码只接受数字） |
| GET/PUT | `/api/holdings` | 读取/保存持仓与设置（整份 JSON 覆盖写） |
| POST | `/api/refresh` | 后台线程刷新全部；`GET /api/status` 查进度 |
| GET | `/api/lookup?code=` | 按代码查名称（腾讯行情），返回市场、币种、是否已在池中 |
| POST | `/api/stocks` | `{code,name?,industry}` 追加到 `stocks.csv` 并后台刷新该只；池中已有→409；正在刷新→409 |
| DELETE | `/api/stocks/<code>` | 从 `stocks.csv`、`pool.json`、详情和缓存中移除（不动持仓） |
| GET | `/api/version`、`/api/update[?force=1]` | 版本；检查更新 |
| GET | `/api/access`、POST `/api/passcode`、`/login` | 局域网地址与访问密码 |
| GET | `/api/qr?u=` | 手机访问二维码（只给内网地址生成） |
| GET | `/changelog.md` 等静态文件 | 前端资源 |

安全：只接受内网/本机/链路本地客户端（防止路由器端口映射暴露公网）；可选访问密码（加盐哈希存 `access.json`）。写操作用全局锁 `_lock`。

## 6. 数据流（刷新一只股票）

`compute()`：取分红（按市场分流）→ 取不复权日线（增量缓存）→ 按除息日构造「价格指数」和「含分红再投总回报指数」→ 算股息率序列、5 年分位、买入区间 → 年度明细、分红节奏、未来 12 个月预计分红 → 公司体检（仅 A 股个股）→ 写详情 JSON，返回池汇总条目。详见 `02`。
