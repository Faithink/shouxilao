# 前端约定

前端是单文件 `web/index.html`（HTML + CSS + JS），无构建、无外部依赖。视觉规范见根目录 `DESIGN.md`（**所有颜色、形状、字体都用 `:root` 变量，不要直接写色值**）。

## 1. 结构

- 路由：哈希路由，`/#/`（股票池）、`/#/hold`（持仓）、`/#/learn`（红利课堂）、`/#/settings`（设置）、`/#/stock/<code>`（详情）。`route()` 解析哈希并 `render()`；点页头 logo/标题回首页并清除筛选。
- 全局状态 `state`：`pool`、`holdings`、`detail`、`cache`（个股详情缓存）、`sort`、`f`（筛选：`q` 搜索、`ind` 行业、`st` 状态、`mk` 市场）、`refreshing` 等。
- 主渲染函数：`renderPool / renderDetail / renderHold / renderLearn / renderSettings`；都是「拼模板字符串 → 写入 `#main` → 绑定事件」。输入框事件只刷新表格不重建输入框（避免打断中文输入法）。
- 数据：`api(path)` 封装 fetch（401 跳登录）；`getStock(code)` 读详情并调用 `applyZones`；`saveHoldings()` 整份覆盖保存。
- 手机：另有一套排版（`@media(max-width:620px)`）：底部三个标签栏、股票池按卡片显示、触控区放大、输入框不触发 iPhone 自动缩放。

## 2. 通用组件与约定

- **页内对话框**：`dlg({title,msg,fields,ok,cancel})`、`askConfirm(msg,ok)`、`notice(msg)`。**不要用原生 `confirm/prompt/alert`**——内置浏览器和 WebView 会屏蔽。
- **折叠卡片**：全局 `fold()`（`details.card.fold`，右侧小箭头）；设置页「行业溢价」「个股单独设定」默认折叠，展开状态存在 `state.openFolds`。
- **版本说明**：`/changelog.md` 由 `mdLite()` 极简 Markdown 渲染（标题、列表、加粗）。写版本说明时不要出现字面的星号加粗标记（渲染器会弄乱）。
- **检查更新**：设置页按钮 + 每天自动查一次；有新版在页面顶部 `#updbar` 显示（可关闭，同版本不再提醒，存 `localStorage.updDismiss`）。
- **隐私模式**（持仓页眼睛按钮 `#privbtn`）：`applyPrivacy()` 遍历文本节点，把金额、份额、收益、日期、代码变成 `**`；个股名变成「首字+`***`」；所属行业也遮；价格位置结论、加仓止盈节点直接移除；状态徽章变 `***`。新增页面内容时要确认没有泄漏。
- **拼音搜索**：`/api/pool` 返回每只股票的 `py/pyfull`，搜索支持名称、代码、拼音缩写（如 `zgsh`）。
- 价格显示 `px()`（ETF 3 位小数）；金额 `cny()`（≥1 万显示「x.xx万」）；百分比 `pct()`。
- 币种辅助：`CU/CS/cu(d)/mkt(d)/taxOf(d,days)/fxOf(d)/cnyView(d)`，见 `03_算法口径.md` §3。
- `localStorage` 一律包 try/catch：外观主题、关注列表、隐私模式、上次选的市场 `mk`、更新提示已关闭版本。持仓、设置保存在 `holdings.json`（服务端）。

## 3. 股票池页（`renderPool`）筛选布局（1.6.0）

自上而下三层，**按使用频率和性质区分形态**：

1. **顶部行**：左 = 市场分段开关 `#mkseg`（A 股 / B 股 / 港股 / 全部，各带数量；池里没有 B 股、港股时整个开关隐藏；默认 A 股；选择记在 `localStorage.mk`），右 = 搜索框 `#fq`。**搜索时不受市场限制**。手机上搜索框单独占一行。
2. **状态胶囊**：重点关注（持仓+手动关注）/ 精选（系统筛选，单独一项）/ 全部 / 低位 / 偏低 / 适中 / 偏高 / 高位（带数量）。这是主筛选。
3. **行业胶囊 `#indstrip`**：**单行横向滑动**（右侧渐隐提示），按当前范围内数量从多到少排，数量为 0 的行业隐藏（已选的除外），选中后自动滚到居中。**不要再用行业下拉框**（用户明确不喜欢，手机上列表太长）。切换市场时清掉行业筛选。

数量和列表都基于「当前市场 + 当前状态」计算；`state.f.mk` 为空字符串表示「全部」。

## 4. 其他页面要点

- **详情页**：价格区间条、股价 vs 含分红再投（10 年）、股息率走势（含买入/止盈线）、年度分红柱、分红节奏、年度明细、历次分红与已公告方案、公司体检卡（A 股个股）；顶部按钮：加入关注、持仓录入、**移出股票池**（`DELETE /api/stocks/<code>`，不影响持仓）。港股/B 股显示币种标签；ETF 显示「元/份」。
- **持仓页**：一只股票一行（`holdTable`），点开看节点、批次、分红；多行录入（日期、方向买入/卖出、成交价、数量）；分红日历 `divCal`；已实现盈亏卡；配置分析；有港股/B 股时底部说明汇率和税率。
- **设置页**：外观、数据（刷新）、**添加个股**（代码→查询→改名/选行业→加入；加入后 `poll()` 轮询状态并刷新）、手机使用（二维码；安卓独立版 UA 含 `ShouxiApp` 时隐藏）、买入要求（国债收益率 + 行业溢价 + 个股单独设定）、关于（联系方式、检查更新、内嵌版本说明）。
- **红利课堂**：约 11 节，带目录与「↑ 目录」按钮，多处可拖动滑块（股息率两面、总回报、溢价阶梯、红利再投、攒股息模拟器等）。内容是通用知识，不推荐具体产品。

## 5. 改前端时的检查清单

1. 颜色/形状查 `DESIGN.md`；图表最多两种数据色 + `--bad`；柱形不按好坏上色。
2. 中文句子里的标点用全角。
3. 新增文案避免「推荐买入」之类措辞；需要时加「仅供研究，不构成投资建议」。
4. 在隔离数据目录跑一遍：4 个主页面 + 个股详情不报错；手机宽度（375）没有横向溢出；隐私模式下没有泄漏。
5. 不要在代码里写死股票数量。

## 补充：管理股票池与更新弹窗

- **移出个股**：公共函数 `removeStock(s)`（详情页「移出股票池」和设置页「管理股票池」共用）。服务端 `DELETE /api/stocks/<code>` 在持仓里仍有该股的买入或卖出记录时返回 409 拒绝；成功后前端清理 `settings.favorites`、`settings.overrides`，并把 `{code,name,industry}` 记入 `settings.removed`（随持仓备份走）。设置页「已移出」列表点「恢复」会重新 `POST /api/stocks` 下载数据（关注和单独设定不恢复）。
- **检查更新**：新版本用弹窗（`showUpd` 建 `.mask > .dlg.updlg`）：版本、发布日期、更新要点、下载链接+提取码；自动检查的弹窗有「稍后再说」「这个版本不再提醒」（`localStorage.updDismiss`），设置页手动检查只有「关闭」。已去掉原来的顶部横幅 `#updbar`。

## 今日提醒与使用指引（2026-11）
- **今日提醒**（`digest()` / `nodeHit()` / `todayBody()` / `bellRender()`）：页头铃铛（`#bell`，带数字角标，没有持仓也没有关注时隐藏）点开浮层 `#bellpanel`（手机上是页头下方的整宽面板；点外面、Esc、换页关闭），不再占股票池页面。内容：持仓里触发的节点（止盈二档 ≥ 高位线×1.15、止盈一档 ≥ 高位线、加仓二档 ≤ min(低位线, 成本×0.9)、加仓一档 ≤ 买入价，各取最高一档，`nodeHit(d,avg)` 要求 d 和 avg 同币种）+ 你关注但没持仓、价格在买入区及以下的股票；加仓和可建仓项带 ⚠。同一份数据还用在：股票池行内小标签（`.ntag`：加仓/止盈档位、可建仓）和持仓页行内的档位标签（没有单独的「有提醒」筛选分类，已去掉）。隐私模式下 `.ntag` 隐藏。目前没有系统通知。
- **使用指引**（`GUIDE` / `showGuide(startAt)`）：启动后默认弹出，4 页以图示为主：①三个入口卡片 ②五档价格位置色条 + 重点关注/精选对比 + 体检五灯 ③加仓/止盈节点阶梯图 ④「自定义股息率要求」：国债 + 行业溢价 + 个股追加 = 要求的拼条（输入框实时算买入价和低位线）+ 三个层级按钮。每页的按钮用 `data-go` 跳到对应位置并高亮：`GUIDE_GO` 里的 pool/hold/rf/prem/ov，调用 `spotlight(find,text)`（等目标出现 → 展开所在 `details` → 滚到中间 → `.spot` 描边 + `data-spot` 小标签，点页面或 9 秒后消失）。跳走后右下角出现「← 回到使用指引」（`#guideback`，回到离开的那一页）。最后一页「下次不再显示」选中并点「开始使用」才存 `settings.guideHide`（随 holdings.json，备份带走）；Esc/跳过/点遮罩只关闭。设置页「使用指引」可再看。指引打开时更新提示排队到指引关闭后（`state.pendingUpd`）。新增样式类名别和已有的撞（`.gbar` 已是价格条，要求拼条用 `.greq`）。

- **红利课堂**：导航标签叫「红利课堂」（手机底栏「课堂」）。⑫「怎么定你的要求股息率」用 `reqBlock("l")` + `bindReqCalc`（和使用指引第 4 页共用，id 前缀不同），三层按钮 `data-lgo` 调 `GUIDE_GO` 跳转高亮。新增章节要同步 `TK`、`GROUPS_L`、标题前缀正则（现含 ⑫）。

## 红利课堂：一课一课（2026-11）
- `renderLearn` 先把所有章节渲染进 DOM，再用「课程模式」只显示当前一课：`LESSONS`（来自 `GROUPS_L` 展开，共 11 课；**课序号 = 在 `GROUPS_L` 里的位置**，id 不随课序变，已并入关系：`sec-7`→`sec-1`、`sec-3`→`sec-2`、`sec-10`→`sec-9`，`sec-11`（怎么用五步）并入开篇 `sec-0`）、`state.lesson`（当前课，`"done"` 表示全部学完）、`settings.learned`（已学课程 id，存 holdings.json，随备份走）。目录 `#toc` 是课程选择（`a[data-lesson]`，当前课 `.on`、已学 `.done` 打 ✓），`#lnav` 是上一课/学完了下一课，`#lcongrat` 是学完的鼓励页（含「再学一次」清空进度）。默认打开第一个没学完的课，都学完了就直接显示鼓励页。
- 新增或调整课序：模板里加 `<div class="card" id="sec-N"><h2>标题：副题</h2>…`（标题取冒号前，前面的圈号数字会被去掉，不要在正文里用「①」这类序号互相引用，直接写课名），同步 `TK`（导语，也用作「下一课」预告）和 `GROUPS_L`（分组即学习路线，显示的课序号自动按顺序生成）。
- ⑫ 公司体检（`#sec-12`，阈值和 `fetch_data.compute_health` 一致，改阈值要两边一起改；带分红率小演示 `bindHealthDemo`）；⑬ 怎么定要求股息率（`reqLab`/`bindReqLab`：色块里是可直接修改的输入框，下面是买入价尺 `.pscale`（低位线/买入价/现价针）、判断文字、「要求每提高 1 个点」的买入价对比条）。使用指引第 4 页仍用 `reqBlock`/`bindReqCalc`。
- 目录 `#toc` 是五段「路线图」：每段一行，组名在左，课程是药丸（`.tcl` 里的 `a.tl`，别用 `.tlist`，那个类名已被占用）。开篇卡片里的「去学…」链接用 `data-lesson-go` 跳课。
- 课程标题统一为名词短语（≤8 字），一句话结论放在 `TK`；模板里 `<h2>` 只写标题。`#lnav`/`#lcongrat` 要靠 `[hidden]{display:none!important}` 才真正隐藏（它们自己有 display 样式，光设 hidden 属性不够）。
- 课程目录 `#toc` 现在是一张紧凑卡片：左边「第 N 课 · 标题」+「已学 n / 11 课」，中间 11 个编号圆点（`.tdots a[data-lesson]`，当前课实心、已学打 ✓，悬停显示课名），右边「目录 ▾」展开成按段分列的课名列表（`.tocg`，桌面 5 列、中屏 3 列、手机 2 列，默认隐藏）。没有单独的进度条（圆点的 ✓ 就是进度，不要重复加）。paint/点击一律用 `#toc a[data-lesson]`，同时覆盖圆点和药丸。手机上圆点单独占一行铺满宽度。
- 学完全部课程时 `confetti()` 放 3 秒 canvas 礼花（只在点「学完了」完成最后一课时放，页面加载时不放；系统开了"减少动态效果"就跳过）。股票池表格里价格位置列的 ⚠ 提示必须允许换行（`td.vtd`），否则「低位」这类带多条提示的列表会撑宽表格、出现横向滚动。
- 股票池表格（桌面）用 `table-layout:fixed` + 列宽（现价 9%、股息率 9%、价格位置 26%、体检 13%、买入价 12%，序号列 44px，名称取剩余），保证切换筛选时各列位置不跳。不要把这些列改回自适应宽度，否则内容（⚠ 提示、长名字）不同，列宽就会随筛选结果变化。
- **使用指引现在 5 页**：第 4 页「自定义股息率要求」改用 `reqMini`/`bindReqMini`（色块里直接改数字，下面给买入价和低位线两个小卡，没有重复的输入行；`reqBlock`/`bindReqCalc` 已删）；第 5 页「加入交流群」带二维码，`last:1`，「下次不再显示」勾选在这页。
- **交流群入口** `commCard()`（设置页 `#commcard` 和指引第 5 页共用）：二维码放 `web/wechat-qr.png`，**没有这个文件就自动只显示微信号**（`onerror` 加 `.noqr`）；微信号常量 `WECHAT_ID`。换二维码只要替换该图片。复制按钮统一用 `bindCopy(root)`。
- **持仓页顶部**：A/B 股区 3 张 KPI 卡（市值/成本、未来 12 月预计分红（小字带税后）、综合收益率 = (浮盈 + 已收分红 − 若今天卖出补税) ÷ 成本）；`ovAll`「总览」只在同时有 A/B 股和港股持仓时出现，港股用 `fxOf(d)` 折人民币（成本也按当前汇率，不含汇率盈亏）；隐私模式下隐藏占比条（`.ovbar`）。
- **刷新**：设置页「更新价格」= `POST /api/refresh {"mode":"quick"}`，分红、财务用 `data/cache/slow/*.pkl`（`datasrc._slow_cached` 包装的 `fetch_dividends/fetch_finance/fetch_etf_dividends/fetch_hk_finance`，TTL 7 天）；「完整刷新」= `mode:"full"`（TTL 0）。`fetch_data.run` 刷完一遍后，价格日期比最新日期落后 >3 天的股票，歇 40 秒再补刷一轮。
- **价格落后标识**：`staleOf(s)`（落后全池最新日期 >3 天）→ 列表名称下 `.stale` 小标签 + 详情页现价提示。
- **我收到的分红**：`holdings.divs = [{id,code,date,amount(税后实收,股票自己的币种),note}]`；`renderHold` 里某股票有记录就用 `rc={gross:Σamount×fx,tax:0,actual:true}` 覆盖估算（表格 `.actm` 标「实」）；服务端 `PUT /api/holdings` 要求 `divs` 是列表。
- **自动备份**：`PUT /api/holdings` 成功后 `rolling_backup()` 写 `HOME/backups/holdings-YYYYMMDD.json`，保留 7 份；`GET /api/backups`、`POST /api/backups/restore {name}`（名字严格匹配 `holdings-YYYYMMDD.json`，恢复前当前持仓先留 `.bak`）；设置页「自动备份」列表。
