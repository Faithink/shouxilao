# 前端约定

前端是单文件 `web/index.html`（HTML + CSS + JS），无构建、无外部依赖。视觉规范见根目录 `DESIGN.md`（**所有颜色、形状、字体都用 `:root` 变量，不要直接写色值**）。

## 1. 结构

- 路由：哈希路由，`/#/`（股票池）、`/#/hold`（持仓）、`/#/learn`（红利课堂）、`/#/settings`（设置）、`/#/stock/<code>`（详情）。`route()` 解析哈希并 `render()`；点页头 logo/标题回首页并清除筛选。
- 全局状态 `state`：`pool`、`holdings`、`detail`、`cache`（个股详情缓存）、`sort`、`f`（筛选：`q` 搜索、`ind` 行业、`st` 状态、`mk` 市场）、`refreshing` 等。
- 主渲染函数：`renderPool / renderDetail / renderHold / renderLearn / renderSettings`；都是「拼模板字符串 → 写入 `#main` → 绑定事件」。输入框事件只刷新表格不重建输入框（避免打断中文输入法）。
- 数据：`api(path)` 封装 fetch（401 跳登录）；`getStock(code)` 读详情并调用 `applyZones`；`saveHoldings()` 整份覆盖保存。
- 手机：另有一套排版（`@media(max-width:620px)`）：底部三个标签栏、股票池按卡片显示、触控区放大、输入框不触发 iPhone 自动缩放。

## 2. 通用组件与约定

- **页内对话框**：`dlg({title,msg,fields,ok,cancel})`、`askConfirm(msg,ok)`、`notice(msg)`。**不要用原生 `confirm/prompt/alert`**——内置浏览器和 WebView 会屏蔽。
- **折叠卡片**：全局 `fold()`（`details.card.fold`，右侧小箭头）；设置页「行业溢价」「个股单独设定」默认折叠，展开状态存在 `state.openFolds`。
- **版本说明**：`/changelog.md` 由 `mdLite()` 极简 Markdown 渲染（标题、列表、加粗）。写版本说明时不要出现字面的星号加粗标记（渲染器会弄乱）。
- **检查更新**：设置页按钮 + 每天自动查一次；有新版在页面顶部 `#updbar` 显示（可关闭，同版本不再提醒，存 `localStorage.updDismiss`）。
- **隐私模式**（持仓页眼睛按钮 `#privbtn`）：`applyPrivacy()` 遍历文本节点，把金额、份额、收益、日期、代码变成 `**`；个股名变成「首字+`***`」；所属行业也遮；价格位置结论、加仓止盈节点直接移除；状态徽章变 `***`。新增页面内容时要确认没有泄漏。
- **拼音搜索**：`/api/pool` 返回每只股票的 `py/pyfull`，搜索支持名称、代码、拼音缩写（如 `zgsh`）。
- 价格显示 `px()`（ETF 3 位小数）；金额 `cny()`（≥1 万显示「x.xx万」）；百分比 `pct()`。
- 币种辅助：`CU/CS/cu(d)/mkt(d)/taxOf(d,days)/fxOf(d)/cnyView(d)`，见 `03_算法口径.md` §3。
- `localStorage` 一律包 try/catch：外观主题、关注列表、隐私模式、上次选的市场 `mk`、更新提示已关闭版本。持仓、设置保存在 `holdings.json`（服务端）。

## 3. 股票池页（`renderPool`）筛选布局（1.6.0）

自上而下三层，**按使用频率和性质区分形态**：

1. **顶部行**：左 = 市场分段开关 `#mkseg`（A 股 / B 股 / 港股 / 全部，各带数量；池里没有 B 股、港股时整个开关隐藏；默认 A 股；选择记在 `localStorage.mk`），右 = 搜索框 `#fq`。**搜索时不受市场限制**。手机上搜索框单独占一行。
2. **状态胶囊**：重点关注 / 全部 / 低位 / 偏低 / 适中 / 偏高 / 高位（带数量）。这是主筛选。
3. **行业胶囊 `#indstrip`**：**单行横向滑动**（右侧渐隐提示），按当前范围内数量从多到少排，数量为 0 的行业隐藏（已选的除外），选中后自动滚到居中。**不要再用行业下拉框**（用户明确不喜欢，手机上列表太长）。切换市场时清掉行业筛选。

数量和列表都基于「当前市场 + 当前状态」计算；`state.f.mk` 为空字符串表示「全部」。

## 4. 其他页面要点

- **详情页**：价格区间条、股价 vs 含分红再投（10 年）、股息率走势（含买入/止盈线）、年度分红柱、分红节奏、年度明细、历次分红与已公告方案、公司体检卡（A 股个股）；顶部按钮：加入关注、持仓录入、**移出股票池**（`DELETE /api/stocks/<code>`，不影响持仓）。港股/B 股显示币种标签；ETF 显示「元/份」。
- **持仓页**：一只股票一行（`holdTable`），点开看节点、批次、分红；多行录入（日期、方向买入/卖出、成交价、数量）；分红日历 `divCal`；已实现盈亏卡；配置分析；有港股/B 股时底部说明汇率和税率。
- **设置页**：外观、数据（刷新）、**添加个股**（代码→查询→改名/选行业→加入；加入后 `poll()` 轮询状态并刷新）、手机使用（二维码；安卓独立版 UA 含 `ShouxiApp` 时隐藏）、买入要求（国债收益率 + 行业溢价 + 个股单独设定）、关于（联系方式、检查更新、内嵌版本说明）。
- **红利课堂**：约 11 节，带目录与「↑ 目录」按钮，多处可拖动滑块（股息率两面、总回报、溢价阶梯、红利再投、攒股息模拟器等）。内容是通用知识，不推荐具体产品。

## 5. 改前端时的检查清单

1. 颜色/形状查 `DESIGN.md`；图表最多两种数据色 + `--bad`；柱形不按好坏上色。
2. 中文句子里的标点用全角。
3. 新增文案避免「推荐买入」之类措辞；需要时加「仅供研究，不构成投资建议」。
4. 在隔离数据目录跑一遍：4 个主页面 + 个股详情不报错；手机宽度（375）没有横向溢出；隐私模式下没有泄漏。
5. 不要在代码里写死股票数量。

## 补充：管理股票池与更新弹窗

- **移出个股**：公共函数 `removeStock(s)`（详情页「移出股票池」和设置页「管理股票池」共用）。服务端 `DELETE /api/stocks/<code>` 在持仓里仍有该股的买入或卖出记录时返回 409 拒绝；成功后前端清理 `settings.favorites`、`settings.overrides`，并把 `{code,name,industry}` 记入 `settings.removed`（随持仓备份走）。设置页「已移出」列表点「恢复」会重新 `POST /api/stocks` 下载数据（关注和单独设定不恢复）。
- **检查更新**：新版本用弹窗（`showUpd` 建 `.mask > .dlg.updlg`）：版本、发布日期、更新要点、下载链接+提取码；自动检查的弹窗有「稍后再说」「这个版本不再提醒」（`localStorage.updDismiss`），设置页手动检查只有「关闭」。已去掉原来的顶部横幅 `#updbar`。
