# 决策准则与踩坑

## 1. 产品准则（不要轻易打破）

1. **纯本地**：持仓、自选、设置、行情都在用户自己电脑上，不上传、没有账号、没有服务器。因此做不了真正的内测码/账号体系，只能弱校验——讨论过但没做，**不要写进版本说明**。
2. **每台机器数据独立**：打包版不带作者的持仓；首次运行从出厂种子复制；升级只补新增股票、不动用户数据。
3. **体积尽量小**：后端只用标准库，不依赖 pandas/numpy；打包版不带 akshare。
4. **研究工具，不是荐股**：不给个股推荐；买入价是「价格相对你的要求处于什么位置」，不是预测；所有页面和宣传文案带「不构成投资建议」。
5. **口径克制、可解释**：买入要求 = 国债收益率 + 行业风险溢价（股债利差框架）；体检五项各自评级、**不合并总分**；⚠ 提醒不改写档位；周期股用 3 年平均分红避免高点虚高。
6. **宁可不显示，不显示错的**：ETF、对应不到 A 股的 B 股、财务数据不全的港股没有公司体检就不给体检；数据不足显示「无足够数据」；红利税是估算，明说「以券商为准」。
7. **A 股优先**：大多数用户关注 A 股，所以市场筛选默认 A 股，B 股/港股是补充；只有 A 股时界面不出现多余控件。
8. **视觉统一**：只用 `DESIGN.md` 里的变量；数据色最多两种；位置五档、风险四类、体检灯各用各的语义色，不挪作装饰。

## 2. 用户偏好（项目主人）

- 沟通用中文，简短、给结论；长任务中途简单说明进度。
- 不喜欢**下拉框**（长列表难选，手机更糟）；喜欢分段开关、横滑胶囊、折叠卡片、右侧小箭头。
- 隐私模式调过很多次：遮住金额/份额/收益/日期/代码，个股名只留首字，价格位置结论也移除。
- 版本说明要**简短**：只说修复了什么、新增了什么、新增多少只个股；不讲 bug 原因；0.2.0–0.8.0 的内测记录可以更简略；**不提内测系统**。
- 联系方式在「设置→关于」里（微信号、公众号「快乐收息佬」happyshouxilao、小红书「收息佬」ID happyshouxilao、邮箱 shouxilao@foxmail.com——邮箱后缀 `.com` 未经用户确认）。
- 要求发布前**全面测试**再打包；打包的是 Mac + Windows（安卓单独要求才做）；不要打进自己的持仓。
- 小红书文案要避开个股推荐，并鼓励读者「自己拖动滑块试一试」（红利课堂的可拖动图）。

## 3. 版本说明写法（`web/changelog.md`）

- 顶部一句话口号 + 升级说明（数据不会丢；Mac 先退出再替换；Windows 新文件夹覆盖；1.5.0 及以前没有检查更新要手动装一次）。
- 每个版本：标题带日期；「修复」只写现象不写原因；「新增」写清数量（如「新增 9 只个股，股票池共 59 只」）。
- 不要出现字面星号加粗（渲染器会乱），不要提内测码。

## 4. 历史坑与根因

| 问题 | 根因 | 处理 |
|---|---|---|
| 中文 Windows 上点「刷新数据」后个股详情、持仓页打不开 | Python 默认编码在中文 Windows 是 GBK，写文件用了默认编码，读回时乱码 | 全部显式 UTF-8 读写；读取用 `read_text_any`/`load_json`（utf-8-sig→gbk 兜底）；用 `-X warn_default_encoding` 把编码警告当错误做回归 |
| 记事本保存的 `stocks.csv` 读不出 | 带 BOM 或 GBK | 同上，容忍读取 |
| 用户看到 8897 端口/「数据没了」 | 那是测试服务或已装的打包版（数据目录不同），不是开发版 | 讲清楚三类实例；测试结束要关掉 |
| 内置浏览器/WebView 里 confirm/prompt 无效 | 被屏蔽 | 用页内 `dlg/askConfirm/notice` |
| 状态徽章全一个颜色 | `.badge` 类名冲突 | 章节徽标改名 `.snum` |
| 版本说明里 `**` 字面显示错乱 | `mdLite` 渲染器限制 | 文案不用星号 |
| Android 模拟器 CI：路由 `#` 丢失、Google 服务崩溃、Python 重复启动 | 设备 shell 把 `#` 当注释；镜像类型；并发启动 | 用 `route` 名称参数；换镜像重试；Python 启动加同步锁 |
| 港股腾讯日线 501 | 腾讯对港股/频繁请求限流 | 港股、B 股价格改用东方财富 push2his 优先，腾讯备用；失败保留旧数据，隔会儿重试 |
| 批量刷新偶发 `HTTP 501`/断连 | 数据源限流 | 属预期；重试；不要短时间疯狂探测 |
| 用脚本带浏览器 UA 反复探测数据源被拦 | 安全检查判定为绕过机器人检测 | 探测要克制；用应用自己的代码路径验证；被拦后不要绕过，向用户说明 |
| 港股股息率/买入价异常 | 港股无统一财年，用财年法会没数据 | 港股/B 股/ETF 用滚动 365 天分红基准 |
| 腾讯名称被截断（`XD中国神`） | 腾讯除息日名称带前缀且被截 | 去前缀；添加个股时名称可手改 |
| `latest.json` 版本落后 | 发版后忘改 | 发版清单第 8 步；读回确认 |

## 5. 做事流程约定（给 AI）

- 先看现有代码再改；匹配周围代码的风格，不要引入新框架。
- 改动较大时：`update_plan` 列步骤；测试用隔离目录和端口；测完关服务、清 `/tmp`。
- 不确定的数据口径（税率、汇率、分红解析）要在页面里明说「估算」。
- 对外/不可逆动作（删数据、推标签、改公开仓库）先确认或确认已被授权。
- 汇报要如实：测了什么、没测什么、哪些是推断。遇到工具/检查服务临时失败，如实重试，不要绕过安全检查。
- 提交信息末尾带 Claude Code 提供的 Co-Authored-By 行；不要提交 `holdings.json`、`access.json`。
