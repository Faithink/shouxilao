收息佬 · Windows 使用说明
=======================

1. 把整个「收息佬」文件夹解压到任意位置(比如 D:\收息佬),不要在压缩包里直接运行。
   如果以前装过旧版:先在右下角托盘图标上右键「退出收息佬」,再用新文件夹覆盖旧文件夹即可。你的持仓、自选、设置都在 %APPDATA%\收息佬\ 里,升级不受影响。
   (1.5.0 在中文 Windows 上点「刷新数据」后,个股详情页和持仓页会打不开,1.5.1 已修复,旧数据会自动识别。)
2. 双击「收息佬.exe」。第一次 Windows 会提示"已保护你的电脑"(没有代码签名):
   点「更多信息」→「仍要运行」,只需一次。
3. 打开后右下角托盘(可能在 ^ 隐藏图标里)出现头像图标,浏览器自动打开页面。
   右键托盘图标可以:打开页面、复制手机访问地址、打开数据文件夹、退出。
4. 第一次进入页面,点「更新数据」,等几分钟让数据下载完;之后每次只补最近几天。
5. 想用手机看:Windows 防火墙弹出提示时,勾选「专用网络」并允许;手机和电脑连同一个 WiFi。

你的数据(持仓、自选、设置、行情)保存在这台电脑上:
   %APPDATA%\收息佬\
不会和别人共享。想彻底清除,删掉应用后把这个文件夹也删掉。

系统要求:Windows 10 或更高(64 位)。
本工具只做数据整理与计算,不构成投资建议。

检查更新:设置页最下面有「检查更新」按钮;程序每天也会自动检查一次,有新版会在页面顶部提示。
