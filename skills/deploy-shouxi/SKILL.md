# 部署收息佬

收息佬是一个本地运行的红利股研究工具:股票池、价格位置、公司体检、持仓与红利税测算。纯 Python 标准库 + 单文件网页,**不上传任何持仓数据**。仓库:https://github.com/Faithink/shouxilao (GPL-3.0)。

> 只做数据整理与计算,不构成投资建议。部署过程中不要替用户推荐或评价任何个股。

## 你要做的事(按顺序)

### 1. 看环境
- 判断系统:macOS / Windows / Linux。
- 检查 Python:运行 `python3 --version`(Windows 用 `python --version` 或 `py -3 --version`)。需要 **3.9 以上**。没有就先告诉用户去 https://www.python.org/downloads/ 安装(Windows 安装时勾选 "Add python.exe to PATH"),装好再继续。不要擅自安装系统级软件。
- 检查 git:`git --version`。没有 git 时,让用户从仓库页面点 Code → Download ZIP,解压后进入目录。

### 2. 取代码
```bash
git clone https://github.com/Faithink/shouxilao.git
cd shouxilao
```
目录选在用户有写权限的位置(如用户主目录),不要放进系统目录。

### 3. 装依赖(可选,但建议)
```bash
python3 -m pip install pypinyin segno
```
`pypinyin` 让股票搜索支持拼音缩写(如 sh→神华);`segno` 用来生成手机访问的二维码。装失败也不影响主要功能,可以跳过并告诉用户。

### 4. 启动
```bash
python3 app.py
```
- 终端会打印"本机: http://127.0.0.1:8890"。**地址一定要带端口号**:默认 8890,被占用时自动改用 8891~8899,以终端打印的为准(也记录在项目目录的 `server.port` 文件里)。
- 服务要一直开着,终端不要关;想后台运行,Mac/Linux 可在命令后加 `&`,Windows 另开一个终端窗口。

### 5. 验证
- 请求 `http://127.0.0.1:<端口>/api/version`,应返回 `{"version": "…"}`。
- 请求 `/api/pool`,应有约 170+ 只股票。
- 让用户用浏览器打开 `http://127.0.0.1:<端口>`。第一次打开会弹出"使用指引",按提示点一遍即可。

### 6. 第一次使用的提示(告诉用户)
- 仓库自带一份股票池的数据快照,可以直接用;想要最新价格,在「设置」页点「刷新数据」(约 5~8 分钟,期间可以继续使用,个别港股接口限流时会更久,重新刷一次通常能补上)。
- 持仓、关注、设置保存在项目目录下的 `holdings.json`(私人数据,注意备份,不要上传到网上);设置页有「备份与恢复」。
- 想用手机看:电脑和手机连同一个 WiFi,打开终端里打印的"局域网"地址;建议在终端运行 `python3 passcode.py 你的密码` 设置访问密码。

## 常见问题

| 现象 | 处理 |
|---|---|
| 浏览器显示 404 / 打不开 | 90% 是地址没带端口。用 `http://127.0.0.1:8890`(端口以终端为准),不要只输 127.0.0.1 |
| 提示端口被占用 | 程序会自动换 8891~8899;全部占用才会报错,关掉占用的程序再启动 |
| `python3` 找不到(Windows) | 试 `python` 或 `py -3`;仍不行就按第 1 步安装 Python 并勾选 PATH |
| 刷新数据很慢 / 个别股票价格没更新 | 数据源(东方财富、腾讯、新浪)会临时限流,等一会儿再点一次「刷新数据」 |
| 用户问怎么升级 | 在项目目录 `git pull`,重启 `python3 app.py`;持仓数据不受影响 |

## 不要做的事
- 不要改动、上传、读取用户的 `holdings.json` 内容。
- 不要把服务绑定到公网,不要做端口映射;只用于本机和同一 WiFi。
- 不要推荐个股,也不要把工具里的"低位""精选"说成买入建议。
